# ☕ World Café - II Workshop Região Sudeste

O **World Café - II Workshop Região Sudeste** é uma aplicação web desenvolvida para explicar, de forma clara e interativa, como funciona a dinâmica do **World Café** em um workshop presencial. A página organiza os objetivos, a estrutura das rodadas, os papéis de anfitriões e apoios, os materiais necessários e os combinados da equipe, servindo como guia de preparação para a condução da atividade.

A proposta é transformar orientações metodológicas em uma experiência digital acessível, visual e fácil de consultar durante o planejamento e a execução do workshop.

## ✨ Funcionalidades

- Apresentação estruturada da metodologia World Café
- Explicação dos objetivos da dinâmica
- Descrição visual da organização das salas e grupos
- Detalhamento das rodadas de conversa
- Orientações sobre o papel do anfitrião
- Orientações sobre o papel do apoio
- Lista de materiais necessários
- Seção de combinados importantes para a equipe
- Layout responsivo e visualmente organizado
- Uso de ícones e blocos temáticos para facilitar a leitura

## 📚 Conteúdo abordado

A página reúne informações sobre:

- o que é o World Café;
- objetivo da dinâmica;
- estrutura geral da atividade;
- funcionamento de cada rodada;
- papel do anfitrião;
- papel do apoio;
- materiais utilizados;
- combinados importantes para a equipe;
- fechamento da atividade.

## 🎯 Objetivo do Projeto

O projeto foi criado para servir como material de orientação para equipes envolvidas na condução do **II Workshop Região Sudeste**, apresentando de maneira didática como a metodologia do World Café será aplicada no evento.

A página ajuda participantes da organização a compreenderem:

- a lógica da dinâmica;
- a distribuição dos grupos;
- os tempos de cada rodada;
- as responsabilidades de cada papel;
- a importância da escuta e da construção coletiva.

## ▶️ Como usar

1. Abra o arquivo HTML em um navegador moderno.
2. Leia a introdução sobre o conceito de World Café.
3. Navegue pelas seções para entender a dinâmica completa.
4. Utilize a página como apoio para preparação da equipe antes do workshop.
5. Consulte os blocos sobre papéis, materiais e combinados durante o planejamento.
